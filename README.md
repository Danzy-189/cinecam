# CineCam

Кинематографическая камера для съёмки видео в Minecraft.

**Minecraft 1.21.1 · NeoForge 21.1.235 · клиентский мод** — на сервер ставить не нужно, работает в одиночной игре и на любых серверах.

## Идея

Нажимаешь `F6` — камера отцепляется от персонажа. Персонаж остаётся на месте и полностью виден в кадре, а ты летаешь камерой.

`V` возвращает управление персонажу, при этом камера **остаётся висеть** и продолжает работать в своём режиме: смотрит на тебя, облетает по орбите или летит следом. Ты в это время играешь обычно: ходишь, ломаешь и ставишь блоки — всё снимается со стороны.

`H` прячет весь интерфейс для чистого кадра.

> Мод не пишет видеофайл — он даёт операторскую камеру. Запись делается OBS / ShadowPlay / любым рекордером.

## Режимы камеры

| Режим | Что делает |
| --- | --- |
| **Свободная** | Полный ручной полёт: мышь крутит камеру, WASD / Space / Shift двигают её |
| **Трекер** | Камера висит там, где ты её оставил, и всегда держит персонажа в кадре |
| **Орбита** | Камера сама облетает персонажа по кругу: W/S — радиус, Space/Shift — высота, A/D — докрутка |
| **Следование** | Камера-дрон: держит смещение относительно персонажа, летит за ним и смотрит на него |

В режимах Трекер / Орбита / Следование наведение автоматическое — можно спокойно переключиться на персонажа, камера снимает сама.

## Клавиши по умолчанию

Переназначаются в Настройки → Управление → категория **CineCam**.

| Клавиша | Действие |
| --- | --- |
| `F6` | Вкл / выкл режим камеры |
| `V` | Переключить управление: камера ↔ персонаж (камера остаётся висеть) |
| `C` | Следующий режим камеры |
| `H` | Скрыть / показать интерфейс |
| `N` | Окно настроек камеры (без паузы) |
| `R` | Вернуть камеру к глазам персонажа |
| `B` | Кинополосы 2.39:1 |
| `G` | Сетка кадра (правило третей) |
| `Z` / `X` | Наклон горизонта (roll) |
| `WASD`, `Space`, `Shift` | Движение камеры |
| `Ctrl` (бег) | Ускорение ×3 |
| Колёсико | Скорость камеры |
| `Ctrl` + колёсико | FOV (зум) |

## Интерфейс

- Компактная HUD-панель: режим, кто сейчас под управлением (CAMERA / PLAYER), скорость, FOV, плавность, координаты и подсказка по клавишам.
- Экран настроек (`N`): выбор режима, ползунки скорости / FOV / плавности / наклона / орбиты, переключатели кадра. Игра не встаёт на паузу, изменения видны сразу.
- `H` гасит весь HUD (включая панель CineCam), но кинополосы остаются.
- Настройки сохраняются в `config/cinecam-client.properties`.

## Как это устроено

- `CameraEntity` — невидимый клиентский штатив (`EntityType.MARKER`, высота глаз 0). В мир не добавляется и на сервер не отправляется — это только точка обзора для `Minecraft#setCameraEntity`.
- `CameraController` — вся логика: состояние, движение с инерцией, автонаведение, орбита, сглаживание. Позиция считается раз в тик, между тиками идёт интерполяция — картинка плавная на любом FPS.
- `ClientEvents` — подписки NeoForge: `ClientTickEvent`, `ViewportEvent.ComputeCameraAngles` (yaw/pitch/roll), `ViewportEvent.ComputeFov`, `MovementInputUpdateEvent` (гасит движение персонажа), `InputEvent` (колёсико и блокировка ударов), `RenderGuiLayerEvent.Pre` (скрытие интерфейса).
- Пока управляешь камерой, повороты мыши перехватываются, а поворот персонажа возвращается обратно — модель в кадре стоит неподвижно.
- Когда управляешь персонажем, мод пересчитывает трассировку прицела от глаз игрока, а не от камеры, чтобы ломать и ставить блоки можно было корректно.

## Установка

1. Minecraft 1.21.1 + NeoForge 21.1.235.
2. Положить `cinecam-1.0.0.jar` в папку `mods`.
3. Запустить игру и нажать `F6`.

## Сборка .jar

### Через GitHub Actions (ничего ставить не нужно)

1. Вкладка **Actions** → workflow **Build jar**. Он запускается автоматически при каждом пуше в `main` или вручную через **Run workflow**.
2. Открыть завершённый ран → блок **Artifacts** → скачать `cinecam-jar`.
3. Внутри архива — готовый `cinecam-1.0.0.jar`.

Чтобы сразу получить релиз с файлом:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

Сработает workflow **Release** — соберёт мод и прикрепит `.jar` к релизу.

### Локально

Нужны JDK 21 и Gradle 8.14.2:

```bash
gradle build
```

Jar появится в `build/libs/`. Запуск игры из исходников — `gradle runClient`.

Если хочется привычный `./gradlew`, запусти в Actions workflow **Bootstrap Gradle wrapper** — он сгенерирует и закоммитит файлы wrapper в репозиторий.

## Ограничения

- Камера видит только те чанки, которые загружены у клиента вокруг персонажа. Если улететь слишком далеко — будет пустота.
- Мод клиентский: сервер о камере не знает. Все действия (удары, блоки, предметы) идут от персонажа, как обычно.
- Запись видео — внешними программами (OBS и т.п.).
